    چرا پاک‌نویسWhy paknevis

    ویراستاری دقیق که هیچ‌وقت کد شما را خراب نمی‌کند.A careful copy editor that never breaks your code.

    نیم‌فاصله، حروف عربی، نشانه‌گذاری، رقم‌ها و غلط‌های رایج را درست می‌کند و به کد، لینک، مارک‌آپ و فرمول دست نمی‌زند.It fixes ZWNJ, Arabic characters, punctuation, digits and common misspellings, and leaves code, URLs, markup and math alone.

    🧩

    آگاه از قالبFormat-aware

    متن ساده، Markdown، HTML و LaTeX (با XePersian)؛ بلوک‌های کد، فرانت‌متر، تگ‌ها، فرمول‌ها و \lr{…} محافظت می‌شوند. پشتیبانی اختیاری از ‎.docx.Plain text, Markdown, HTML and LaTeX (XePersian-aware). Code, front matter, tags, math and \lr{…} are protected. Optional .docx support.

    🛡️

    محافظه‌کارConservative by design

    قاعده‌ها فقط در بافت فارسی عمل می‌کنند: Python 3.12 یا «میز» و «میدان» دست نمی‌خورند.Rules act only in Persian context: Python 3.12, 10GB or nouns like «میز» and «میدان» stay untouched.

    🔁

    تکرارپذیرIdempotent

    fix(fix(x)) == fix(x)؛ با تست‌های property-based همراه با «ناحیه‌های محافظت‌شده هرگز تغییر نمی‌کنند».fix(fix(x)) == fix(x), verified with property-based tests, along with “protected regions never change”.

    📏

    ۲۵ قاعدهٔ مستند25 documented rules

    هر قاعده کد (PN203)، نام، شدت، توضیح دوزبانه و مثال دارد و جداگانه قابل خاموش کردن است.Each has a code (PN203), a name, a severity, a bilingual explanation and examples, and can be turned off.

    ⚙️

    قابل پیکربندیConfigurable

    در pyproject.toml: سبک رقم، «خانه‌ی» یا «خانهٔ»، واژه‌نامهٔ اختصاصی و دستورهای paknevis-disable.In pyproject.toml: digit style, «خانه‌ی» vs «خانهٔ», custom dictionaries and inline paknevis-disable comments.

    🔒

    همین موتور، در مرورگرThe real engine, in your browser

    ویرایشگر بالا خودِ پکیج پایتون را با Pyodide اجرا می‌کند؛ پس با CLI همیشه یکسان است و متن شما جایی نمی‌رود.The editor above runs the actual Python package via Pyodide, so it always agrees with the CLI, and your text never leaves the page.

    پرسش‌هاFAQ

    پرسش‌های رایجFrequently asked

    متن من به سروری فرستاده می‌شود؟Is my text uploaded anywhere?

    نه. Pyodide و پکیج یک بار دانلود می‌شوند و همه‌چیز داخل مرورگر اجرا می‌شود. CLI و Action هم کاملاً محلی‌اند.No. Pyodide and the package are downloaded once and everything runs in your browser. The CLI and the Action are fully local too.

    کد و فرمول‌های من را خراب نمی‌کند؟Will it mangle my code or math?

    نه. کد درون‌خطی و بلوکی، URLها، تگ‌ها و ویژگی‌های HTML، فرانت‌متر، $…$، دستورهای LaTeX و محیط‌های verbatim و TikZ محافظت می‌شوند؛ با تست بررسی شده که هرگز تغییر نکنند.No. Inline and fenced code, URLs, HTML tags and attributes, front matter, $…$, LaTeX commands and verbatim/TikZ environments are protected, and tests check they never change.

    چرا بعضی نیم‌فاصله‌ها را اصلاح نمی‌کند؟Why does it skip some ZWNJ fixes?

    پاک‌نویس قاعده‌محور است، نه تحلیلگر کامل صرفی. برای جلوگیری از خطای مثبت، فقط فهرست گزیده‌ای از ستاک‌ها را اصلاح می‌کند. اگر خطایی دیدید جمله را در Issue بفرستید.It's rule-based, not a full morphological analyser. To avoid false positives it only fixes a curated list of stems. Spotted a miss or a false positive? Open an issue with the sentence.

    «خانه‌ی» یا «خانهٔ»؟«خانه‌ی» or «خانهٔ»?

    هر دو. با گزینهٔ ezafe (یا منوی بالا) سبک دلخواهتان را انتخاب کنید؛ رقم‌ها هم فارسی، لاتین یا دست‌نخورده می‌توانند بمانند.Either. Pick your style with the ezafe option (or the menu above). Digits can be Persian, Latin or left as they are.
