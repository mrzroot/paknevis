    در پروژهٔ خودتان

    همین موتور به‌صورت کتابخانهٔ پایتون، خط فرمان، هوک pre-commit و GitHub Action در دسترس است.

    pip install "paknevis @ git+https://github.com/mrzroot/paknevis"
paknevis check docs/          # report
paknevis fix --diff thesis.tex  # preview fixes

    همه‌چیز در مرورگر شما اجرا می‌شود (Pyodide)؛ متنی به سروری فرستاده نمی‌شود.
